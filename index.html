Tecnologia da Informação

Sobre a Tecnologia da Informação

O que é TI?

Tecnologia da Informação (TI) é a área que utiliza computadores, sistemas, redes e dados para criar, processar, armazenar, proteger e transmitir informações.

A TI está presente no desenvolvimento de sistemas, na manutenção de computadores, na comunicação em redes, na segurança da informação e no uso de ferramentas digitais para resolver problemas.

RedesConectam dispositivos e serviços.
SegurançaProtege sistemas e informações.
DadosOrganizam informações para gerar conhecimento.

Resumo

Principais conteúdos estudados na disciplina de Tecnologia da Informação.

Blockchain

Registro digital distribuído que organiza dados em blocos conectados, permitindo rastreabilidade e validação descentralizada.

Bitcoin

Criptomoeda que funciona em uma rede descentralizada e utiliza blockchain para registrar transações.

NFT

Token não fungível: um registro digital único que pode representar itens ou direitos digitais.

Metaverso

Conceito de ambientes digitais imersivos e interativos para comunicação, entretenimento, trabalho e experiências virtuais.

Máquina Virtual

Ambiente criado por software que simula um computador e permite executar sistemas isolados.

Cluster

Conjunto de computadores que trabalham juntos para oferecer mais desempenho, disponibilidade ou capacidade.

Hardware

A parte física dos computadores e dispositivos tecnológicos.

O que é Hardware?

Hardware é o conjunto de componentes físicos de um computador ou dispositivo. São as peças que podemos tocar e que permitem que o sistema funcione.

ProcessadorMemória RAMArmazenamentoMonitorTecladoMouse

Software

Programas e sistemas que dão instruções ao hardware e permitem realizar tarefas.

Sistemas Operacionais

Windows, Linux e outros sistemas responsáveis por gerenciar recursos e permitir a interação com o computador.

Ferramentas e tecnologias

HTML, CSS, JavaScript, Bootstrap e editores de código são utilizados para criar e personalizar páginas e aplicações web.

Git e GitHub

Ferramentas utilizadas para versionar projetos, compartilhar código e publicar sites, inclusive com GitHub Pages.
